# assets/

Drop the media for your video here (sub-folders are fine): footage, images, narration, music, SFX, fonts, SRT/VTT,
script text. Name things helpfully (`narration.wav`, `music_main.mp3`, `sfx/whoosh_01.wav`, `j20_front.jpg`) —
roles and keywords are inferred from names and folders, and Claude will look at the images itself.

Nothing in this folder is committed (see `.gitignore`) and everything in it is treated as untrusted data.
